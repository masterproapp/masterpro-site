What we do

New cabinets have to be level, plumb, and fastened correctly before a countertop can go on top. MasterPro assembles and installs kitchen, bath, and pantry cabinets, and can take the old ones out first.

  • Kitchen cabinets, new or replacement
  • Bathroom vanities
  • Pantry and storage cabinetry
  • Assembling ready-to-assemble (RTA) cabinets
  • Removing existing cabinets

How we do it

Every cabinet install job follows the same process.

  1. Remove the old cabinets

    If needed, we take out the existing cabinets and haul them away.

  2. Assemble and lay out

    We assemble RTA cabinets and mark the layout on the walls.

  3. Set level and plumb

    We shim, level, and fasten every box so it's ready for countertops.

  4. Doors and hardware

    We hang and adjust doors, add hardware, and clean up.

Questions customers ask

Short answers you can give on the spot.

What about countertops?

Cabinets go in first, then countertops are measured. Note who's doing the countertops on the referral so the timing lines up.

Can you hook up the sink and appliances?

MasterPro has licensed plumbing, gas, and electrical in-house in some states. Note it on the referral and we'll confirm what can be done in the same project.

Do you assemble flat-pack cabinets?

Yes. RTA assembly can be included in the quote.

What if a cabinet arrives damaged?

The installer checks every box before installing and flags damage right away so the replacement can be ordered.
